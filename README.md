# Konserwator

Pracownia konserwatorska w kieszeni. Zmywasz brud z arcydzieła, retuszujesz je według numerów, a potem złocisz ramę i kładziesz werniks.

Gra w przeglądarce, stworzona z myślą o iPadzie z rysikiem. Działa też na telefonie i laptopie, również offline jako PWA.

**Zagraj:** https://jakubkapusta.github.io/konserwator/

- **Czyszczenie:** pędzlem zmiatasz kurz i pajęczyny, wacikiem z rozpuszczalnikiem zdejmujesz sadzę i pożółkły werniks, a skalpelem zeskrobujesz zaschnięte krople.
- **Retusz:** wybierasz farbę i malujesz pola z jej numerem. Każde pole odzyskuje prawdziwy fragment obrazu razem z fakturą pędzla.

Obrazy pochodzą z Rijksmuseum (domena publiczna). Dane obrazów przygotowuje offline skrypt w `tools/`, a szczegóły są w `CLAUDE.md`.

```bash
npm install
npm run dev
```
